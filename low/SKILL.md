# Low

Use this profile with the required [shared workflow](../shared/workflow.md),
which covers invocation, repository location, dispatch, and usage.

| Stage | Models and effort |
|---|---|
| Coordinate | Any model (recommended: any) |
| Plan | Sol xhigh OR Opus xhigh |
| Implement | Sol xhigh OR Opus xhigh, selected by remaining quota |
| Review | Prefer the other model, at xhigh, in a fresh context |

Use a short plan that names the intended behavior, affected files, and
verification. A small task still requires independent review.

Choose the planner using available capacity. Recheck usage after planning to
select the builder; planning does not lock in implementation ownership.
If the other reviewer is unavailable or lacks quota, use the same eligible
model in a fresh review session and report that fallback. Never count the
builder's self-check as the mandatory review.

If inspection reveals unresolved architecture, sensitive lifecycle/contract
changes, or repeated failures, explain the evidence and recommend escalation
to high. Continue independent useful work; do not silently change the user's
explicit level or spend outside this model pool.
